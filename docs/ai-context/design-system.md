# Design System Rules

Antes de criar um novo componente:

1. Verificar Developer Playground.

2. Verificar core/components.

3. Reutilizar componente existente.

Não criar:

- Botões fora de PayFlowButton
- Cards fora de PayFlowCard
- Campos fora de PayFlowTextField

---

Componentes Oficiais

PayFlowButton

Variants:

- PRIMARY
- SECONDARY
- DANGER

---

PayFlowStatusBadge

Variants:

- ACTIVE
- CANCELLED
- PENDING
- EXPIRED

---

PayFlowCard

Componente base para:

- Metric Cards
- Subscription Cards

Nunca estilizar Cards locais.
